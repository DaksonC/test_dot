# Prova — Desenvolvedor Backend com foco em IA

Soluções para as 3 questões da prova (enunciado original em `Prova - Backend IA.pdf`).

| Pasta | Questão | Stack |
|---|---|---|
| [`q1_api/`](q1_api/) | API de cadastro e consulta de livros | FastAPI, SQLModel, SQLite, pytest |
